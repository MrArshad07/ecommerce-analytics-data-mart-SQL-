# 📊 E-Commerce Analytics Data Mart (SQL Project)

## 🚀 Project Title
E-Commerce Analytics Data Mart: Customer, Product & Sales Intelligence System using PostgreSQL

---

## 🧠 Project Overview

This project simulates a real-world **analytics system** built using PostgreSQL.  
It transforms raw transactional data into a structured **Data Mart** that supports business decision-making across:

- Customer Analytics
- Product Performance Analytics
- Sales Trend Analysis

The goal is to demonstrate how data analysts design scalable SQL-based reporting systems for business intelligence.

---

## 🏢 Business Context

In a real e-commerce environment companies need to answer:

- Who are the most valuable customers?
- Which products generate the highest revenue?
- How are sales trending over time?
- Which categories contribute most to revenue?

This project solves these questions using advanced SQL.

---

## 🗄️ Database Schema

### 1. dim_customers
Stores customer demographic information.

### 2. dim_products
Stores product catalog, category, and cost details.

### 3. fact_sales
Stores transactional sales data.
